    01 — ANA BEATRIZ

    Histograma de Imagens

    Como podemos entender uma imagem olhando apenas para seus números?

    A imagem é uma matriz

    Cada célula representa um pixel. Cada número representa uma intensidade. O computador trabalha com valores — e o histograma resume como esses valores estão distribuídos.

    Definição

    Contagem de pixels para cada nível de intensidade.

    p(r₁) = n₁ / (M × N)
    r₁ intensidade (0–255)
    n₁ quantidade de pixels
    M × N total de pixels
    MATRIZ 5×5

    02 — CINDY VITÓRIA

    Equalização de Histograma

    Se os pixels estão concentrados em uma faixa estreita, como podemos melhorar o contraste?

    A

    O problema

    Histograma concentrado em faixa estreita = baixo contraste. Pouca utilização da faixa 0–255.

    B

    A solução

    Redistribuir intensidades para obter histograma uniforme. Maior faixa dinâmica = melhor contraste.

    s₁ = (L − 1) · Σ p(rₔ)

    Vantagens

    • Automático
    • Sem parâmetros manuais
    • Melhora faixa dinâmica

    Limitações

    • Amplifica ruído
    • Pode parecer artificial
    • Iluminação não uniforme → CLAHE
