# Referências Bibliográficas

## Referências Principais

### Livro-texto clássico

1. GONZALEZ, R. C.; WOODS, R. E. **Digital Image Processing**. 4th ed. Pearson, 2018.
   - Cap. 3: Intensity Transformations and Histogram Processing
   - Seção 3.3: Histogram Processing (Equalization, Matching)
   - Seção 3.5: Spatial Filtering (Mean, Median)
   - Cap. 10: Image Segmentation (Edge Detection)
   - Seção 10.2: Edge Detection (Sobel, Canny, Laplacian)
   - **ISBN:** 978-0-13-335672-4

2. GONZALEZ, R. C.; WOODS, R. E.; EDDINS, S. L. **Digital Image Processing Using MATLAB**. 3rd ed. Gatesmark Publishing, 2020.
   - Exemplos práticos com MATLAB/Octave
   - Implementação de filtros e equalização

### Livro complementar

1. SONKA, M.; HLAVAC, V.; BOYLE, R. **Image Processing, Analysis, and Machine Vision**. 4th ed. Cengage Learning, 2015.
   - Fundamentos de filtragem e detecção de bordas
   - Aplicações em visão computacional
   - **ISBN:** 978-1-305-65966-3

## Artigos Científicos

1. CANNY, J. **A Computational Approach to Edge Detection**. *IEEE Transactions on Pattern Analysis and Machine Intelligence*, v. 8, n. 6, p. 679-698, 1986.
   - Artigo original do detector de bordas de Canny
   - DOI: 10.1109/TPAMI.1986.4767851

2. SOBEL, I.; FELDMAN, G. **A 3×3 Isotropic Gradient Operator for Image Processing**. *Pattern Classification and Scene Analysis*, p. 271-272, 1973.
   - Operador de gradiente de Sobel
   - Referência original para o kernel de Sobel

3. ZUIDERVELD, K. **Contrast Limited Adaptive Histogram Equalization (CLAHE)**. *Graphics Gems IV*, p. 474-485, 1994.
   - Algoritmo CLAHE para equalização adaptativa
   - Aplicações em imagens médicas

---

## Documentação Técnica

1. OPENCV. **OpenCV Documentation: Image Processing**. Disponível em: <https://docs.opencv.org/>
   - Implementações práticas de filtros, equalização e detecção de bordas
   - Documentação oficial com exemplos em C++ e Python

2. SCIKIT-IMAGE. **scikit-image: Image processing in Python**. Disponível em: <https://scikit-image.org/>
   - Biblioteca Python para processamento de imagens
   - Implementações de filtros, equalização e edge detection

## Notas

- Todas as referências são reais e verificáveis.
- O livro de Gonzalez & Woods é considerado a "bíblia" de processamento digital de imagens e é a referência mais citada na área.
- Os artigos originais de Canny (1986) e Sobel (1973) são de acesso livre through IEEE Xplore e repositórios acadêmicos.
